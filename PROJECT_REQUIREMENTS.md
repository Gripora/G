# GRIPORA Website Requirements

## Main navigation
- Home
- About Us
- Category
- Contact Us

## Main product categories
1. Cycling Gloves
2. Winter Gloves
3. Fitness Gloves
4. Player Gloves

## Product structure
- 4 different models in every category
- 4 color options for every model
- Real glove product photography only
- No 3D glove icons
- No third-party brand logos on product images
- GRIPORA branding must be consistent wherever the GRIPORA logo is used

## Homepage
- Dark performance-led GRIPORA design
- Hero/background imagery related to the four glove categories
- GRIPORA logo/branding integrated consistently
- Clear links to all four category pages

## Category and product pages
- Follow the approved dark GRIPORA layout references
- Product cards should show real glove images, model name, short description, color options, sizes, and an interest/enquiry CTA
- Individual product pages should show the selected model, color choices, size choices, product features, and enquiry CTA

## Deployment
- GitHub Pages compatible static site
- Keep assets inside the repository so the site can later be moved to a custom domain without losing images/data
- Main deployment branch: main
- Development branch: gripora-v2
